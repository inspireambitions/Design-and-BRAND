# Muqabala Arabic style guide

## Voice

- Use clear, neutral Modern Standard Arabic that is understood across the Gulf.
- Write for job seekers with different education levels and first languages.
- Use short sentences, familiar words and direct instructions.
- Sound calm and respectful. Do not sound legal, academic or translated.
- Address the user directly with the common masculine singular form when a neutral sentence is not possible.

## Brand

- Write the brand as `«مقابلة»` in Arabic sentences.
- Do not force the brand name into an awkward grammatical gender. Prefer `نحن` or rewrite the sentence.
- Write Inspire Ambitions as `إنسباير أمبيشنز`.

## Rules

- Use Arabic punctuation in Arabic copy.
- Avoid unexplained technical terms such as `WCAG AA`, `provider`, `pipeline` and `interface`.
- Use `من دون` rather than `بدون` in formal copy.
- Explain privacy as an action: what stays, what is sent and how the user can avoid sending it.
- Never imply that the tool judges the user. It only reviews the evidence in the answer.
