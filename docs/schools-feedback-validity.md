# Assessment Validity Analysis

Assessment: three adviser-approved written practice answers, with four observable rubric elements per question.
Claims to measure: evidence covered by this answer, for formative discussion and revision.
For: adult students in a manually onboarded institution. The institution and its teaching language are not yet confirmed.

## Validity Analysis

Construct validity: exact answer excerpts support present decisions. Server checks reject invented excerpts. The count describes the submitted answer. It does not establish that the event happened or that the person can perform a job.

Construct-irrelevant variance: written fluency, familiarity with interview conventions and access to examples can affect expression. Five synthetic runs preserved concrete evidence written in imperfect English. This is a useful regression check, not proof of fairness across students or languages.

Construct underrepresentation: three short written answers cannot cover all workplace skills. There is no assessment of voice, accent, face, personality or employment prospects. The initial institution must approve question coverage and the precise four elements before use.

## Reliability Analysis

Five repeated concrete synthetic examples each covered 12 elements. Vague and instruction-only examples each covered none. A different answer initially failed twice before saving on its third call. Repeated checks and failure diagnosis remain necessary. Engine confidence labels are not calibrated probabilities. Human agreement has not yet been measured.

## Consequential Validity

Private feedback, question-level retry and a separate adviser view encourage revision. A single prominent total could still encourage writing to a checklist. The report keeps element-level explanation and supporting text visible, and avoids comparing learners.

## Threats Identified

1. Generic rubric wording may leave advisers and the model with different interpretations of an element.
2. An accurate quotation can still receive the wrong interpretation. Exact matching alone cannot establish relevance.
3. A model can treat an invented personal example as evidence because the tool cannot verify events.
4. Synthetic consistency does not establish accessibility or fairness for a real class.

## Recommendations

1. Approve role-specific descriptors and borderline examples with the institution before enrolment.
2. Use evidence corrections with reasons to measure disagreement. Compare first and later attempts only when versions match.
3. State that the tool helps develop an answer and that its evidence count does not verify the underlying event.
4. Run the adult pilot with stated denominators, accessible support and the agreed teaching language. Do not make employment, equality or legal-compliance claims from this test set.

## Overall Verdict

Suitable for controlled formative testing once the remaining release checks pass. The most important content step is institution approval of the questions, rubric descriptors and interpretation examples. This is not a validated selection assessment.
